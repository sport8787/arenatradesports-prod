# METODOLOGIA MYCROFT PUNTER - VALUE BETTING

## 📚 FUNDAMENTOS

### O que é Value Betting?

**Value Betting** é apostar quando a **probabilidade real** de um resultado é **MAIOR** que a **probabilidade implícita** nas odds oferecidas pela casa.

**Fórmula:**
```
Probabilidade Implícita = 1 / Odd × 100

Exemplo: Odd 2.00 → 1/2.00 × 100 = 50%
```

**Value existe quando:**
```
Probabilidade Real > Probabilidade Implícita

Exemplo:
Odd: 2.10 → Probabilidade Implícita: 47.6%
Sua estimativa: 54% de chance
Value: 54% - 47.6% = 6.4% ✅ TEM VALUE!
```

## 📊 METODOLOGIA NETUNO (Análise Probabilística)

Netuno é especialista em **modelos matemáticos** para futebol.

### Expected Goals (xG)

**O que é xG?**
- Métrica que calcula probabilidade de gol em cada finalização
- Baseado em: posição, ângulo, tipo de jogada, pressão defensiva
- Time com xG alto mas poucos gols = azarado (oportunidade!)

**Como usar:**
```
Flamengo vs Vasco
Flamengo: xG 2.8 | Gols: 1
Vasco: xG 0.9 | Gols: 1

Análise: Flamengo criou MUITO mais (2.8 vs 0.9)
Próximo jogo: Apostar em Flamengo tem value!
```

**Importante:**
- xG é tendência, não certeza
- Alguns times superam xG (finalizadores clínicos)
- Outros ficam abaixo (finalizadores ruins)

### Modelo de Poisson

**O que é?**
- Modelo estatístico pra prever gols
- Usa média de gols de cada time (casa/fora)
- Calcula probabilidade de cada placar

**Exemplo simplificado:**
```
Flamengo em casa: média 2.1 gols/jogo
Palmeiras fora: média 1.3 gols/jogo

Usando Poisson:
Flamengo 2x1: 18% de chance
Flamengo 1x0: 16% de chance
Empate 1x1: 14% de chance
```

**Como Mycroft usa:**
- Compara probabilidade do modelo com odds da casa
- Se modelo dá 25% e odd implica 20% → VALUE!

### Indicadores-chave:

**1. Posse de Bola (ajustada)**
- Posse alta + finalizações baixas = INEFICIÊNCIA
- Posse baixa + finalizações altas = EFICIÊNCIA

**2. Finalizações no Gol**
- Mais importante que finalizações totais
- Time com 15 chutes mas só 3 no gol = ruim
- Time com 8 chutes e 6 no gol = perigoso!

**3. Big Chances (grandes chances)**
- Oportunidades claras de gol
- Time que cria muitas mas não converte = azarado (pode melhorar)

**4. Forma Recente (últimos 5 jogos)**
- Pesa mais que toda a temporada
- Time em má fase pode ter odds infladas (value!)

## 💰 CÁLCULO DE VALUE

### Fórmula do Expected Value (EV)

```
EV = (Probabilidade × Lucro) - (1 - Probabilidade × Aposta)

Exemplo:
Aposta: R$ 100
Odd: 2.50
Probabilidade estimada: 45%

Lucro se ganhar: R$ 150 (100 × 2.50 - 100)
Perda se perder: R$ 100

EV = (0.45 × 150) - (0.55 × 100)
EV = 67.50 - 55
EV = +R$ 12.50

EV positivo = VALUE! ✅
```

### Quando APROVAR:

**Critérios mínimos:**
- ✅ EV > 0 (positivo)
- ✅ Value >= 5% (diferença entre prob real e implícita)
- ✅ Odd entre 1.70 e 3.50 (sweet spot)
- ✅ Confiança >= 70%

**Critérios ideais:**
- 🌟 Value >= 10%
- 🌟 Odd entre 2.00 e 2.80
- 🌟 Confiança >= 80%
- 🌟 Casa de apostas líquida (Pinnacle, Bet365)

### Quando VETAR:

- ❌ Value < 5% (marginal demais)
- ❌ Odd < 1.50 ou > 5.00 (extremos arriscados)
- ❌ Confiança < 70% (muita incerteza)
- ❌ Casa suspeita ou odds muito fora da média

## 📈 GESTÃO DE BANCA (Kelly Criterion Adaptado)

### Fórmula de Kelly:

```
% Banca = (Probabilidade × Odd - 1) / (Odd - 1)

Exemplo:
Probabilidade: 50%
Odd: 2.20

% = (0.50 × 2.20 - 1) / (2.20 - 1)
% = (1.10 - 1) / 1.20
% = 0.10 / 1.20
% = 8.3%

Stake: 8.3% da banca (mas use HALF KELLY = 4.15%)
```

**Half Kelly (conservador):**
- Divide resultado por 2
- Menos variância
- Mais seguro pra longo prazo

**Arena Trader (recomendado):**
- Confiança 70-75%: 2% da banca
- Confiança 75-80%: 3% da banca
- Confiança 80-85%: 4% da banca
- Confiança >85%: 5% da banca (MÁXIMO!)

## ⚠️ ARMADILHAS COMUNS

### 1. Viés de Confirmação
- Você QUER que seu time ganhe
- Isso distorce análise
- **Solução:** Analise sem olhar o nome do time primeiro

### 2. Perseguir Perdas (Tilt)
- Perdeu 3 apostas → quer recuperar tudo na próxima
- **Solução:** Stop loss diário! Perdeu 10%? PARE.

### 3. Overvalue em Favoritos
- "Odd 1.30 é garantida!"
- Não existe garantia. Precisa 77% de win rate pra lucrar!
- **Solução:** Só aposte em favorito se tiver VALUE claro

### 4. Confiar Cegamente em Estatísticas
- Stats não contam tudo (motivação, lesões, clima)
- **Solução:** Combine stats + análise qualitativa

### 5. Apostar Muito Cedo
- Odds mudam até o jogo
- Informações novas aparecem (lesões, escalação)
- **Solução:** Aposte mais perto do jogo (1-3h antes)
