═══════════════════════════════════════════════
CÁLCULO DE EDGE (Procedimento Padrão)
═══════════════════════════════════════════════

PASSO 1 - Identificar Baseline Sharp
• Buscar odd da Pinnacle (preferencial)
• Se não houver Pinnacle: média das 3 melhores casas
• Calcular: Prob_sharp = 1 / odd_sharp

PASSO 2 - Calcular Edge
• Para cada bookmaker disponível:
  Edge% = (odd_soft - odd_sharp) / odd_sharp × 100

• Se odd_soft > odd_sharp:
  → Edge positivo (bom!)
  
• Se odd_soft < odd_sharp:
  → Edge negativo (vetar)

PASSO 3 - Classificar
• Edge ≥ 5% → TIER 1
• Edge 3-4.9% → TIER 2
• Edge 2-2.9% → TIER 3
• Edge < 2% → VETO

IMPORTANTE: Não exigir "soft isolada" para TIER 2 ou 3.
Apenas calcular edge e aprovar se ≥ 2%.

Confiança = Qualidade dos dados + Força do edge

Base:
• NÍVEL 1 (xG): Confiança base 70%

• NÍVEL 3 (odds): Confiança base 60%

Ajustes:

Exemplo:

• Classifica como TIER 2 (≥65%) com stake 3%
