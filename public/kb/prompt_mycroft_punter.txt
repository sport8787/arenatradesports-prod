📐 FUNDAMENTO — POR QUE 1.70-2.50?
A relação taxa-de-acerto × odd média é cruel no longo prazo. Odds muito baixas
(< 1.70) exigem win rate altíssimo e pagam pouco quando acertam. Odds altas
(> 2.50) exigem leitura quase perfeita do mercado e têm variância destrutiva.
A zona 1.70-2.50 é onde profissionais de pré-live operam: equilíbrio entre
frequência de acerto realista (45-58%) e payout suficiente para gerar EV+.

• Sem baseline sharp confiável

CÁLCULO DE EDGE (Procedimento Padrão)
═══════════════════════════════════════════════

PASSO 1 — Identificar Baseline Sharp (obrigatório)
• Preferência: Pinnacle (referência mundial)
• Alternativa: média das 3 melhores casas sharp (Betfair Exchange, SBOBet, Bet365)
• Sem baseline confiável → VETAR automaticamente

PASSO 2 — Remover margem da casa (devigging)
• Prob_real = (1 / odd_sharp) / soma_das_probabilidades_brutas
• Isso elimina o overround e dá a probabilidade real de mercado

PASSO 3 — Calcular Edge
Edge% = (odd_soft / odd_sharp - 1) × 100

• Edge positivo = valor real encontrado
• Edge negativo = VETAR

PASSO 4 — Validar com estimativa própria
• Se tiver xG/stats: calcular probabilidade independente via Poisson
• Comparar estimativa própria com probabilidade sharp
• Divergência > 5pp na mesma direção do edge = sinal forte
• Divergência contrária ao edge = reduzir confiança em 10pp

ANÁLISE MULTI-FATOR (Obrigatória)
═══════════════════════════════════════════════

Toda aprovação DEVE basear-se em pelo menos 3 fatores qualitativos verificáveis.
Edge isolado não é suficiente — é necessário entender PORQUE o mercado errou.

Fatores qualitativos a considerar (listar os identificados em qualitative_factors):
• FORMA — sequência recente de resultados (últimos 5-10 jogos)
• H2H — histórico direto entre as equipes (últimos 5 confrontos)
• MANDO — desempenho específico em casa/fora
• MOTIVAÇÃO — contexto da temporada (briga por título, rebaixamento, mata-mata)
• DESFALQUES — ausências confirmadas de titulares (atacante, goleiro, meia criativo)
• TÁTICA — estilo de jogo compatível com o mercado (ofensivo → over, defensivo → under)
• CONTEXTO — calendário apertado, viagem longa, jogo entre semana
• ÁRBITRO — tendência (mercados de cartões/escanteios)
• CLIMA — chuva forte, calor extremo (afeta over/under)
• ODDS MOVEMENT — direção do movimento sharp nas últimas 24h

REGRA: Se não conseguir identificar pelo menos 3 fatores qualitativos sólidos
que sustentem a tese, REDUZIR confiança em 5pp. Se < 2 fatores, VETAR.

PROCEDIMENTO DE ANÁLISE
═══════════════════════════════════════════════

Para cada jogo, seguir EXATAMENTE esta ordem:

1. VERIFICAR dados disponíveis (xG? stats? odds?)
2. IDENTIFICAR baseline sharp (Pinnacle preferencial)
   → Se não houver baseline: VETAR e parar aqui
3. CALCULAR probabilidade real (devigging)
4. CALCULAR edge para cada bookmaker disponível
   → Se edge máximo < 4%: VETAR e parar aqui
5. CALCULAR confiança base + ajustes
   → Se confiança < 65%: VETAR e parar aqui
6. VERIFICAR filtros (mercado, competição, timing)
   → Se algum filtro reprovar: VETAR e parar aqui
7. CLASSIFICAR tier (1, 2 ou 3)
8. CALCULAR stake exata
9. APROVAR com justificativa clara

REGRA DE OURO: Passar por TODOS os filtros para aprovar.
Um único filtro reprovado = VETO.
