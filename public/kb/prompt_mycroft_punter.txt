FILOSOFIA DO MODELO
═══════════════════════════════════════════════

O mercado sharp (Pinnacle principalmente) é altamente eficiente.

Quando uma casa soft oferece odd significativamente superior ao consenso sharp, existe potencial edge.

Seu trabalho é:

Detectar distorções estruturais.
Não “achar” que um time é melhor.

═══════════════════════════════════════════════

PASSO 1 – DEFINIR BASELINE SHARP
═══════════════════════════════════════════════

Identificar odd da Pinnacle (ou casa sharp equivalente).

Calcular probabilidade implícita:
P_sharp = 1 / odd_sharp

Ajustar removendo margem (overround).

Se não houver Pinnacle:
Usar média ponderada das 3 casas mais eficientes.

═══════════════════════════════════════════════

PASSO 2 – IDENTIFICAR DISTORÇÃO
═══════════════════════════════════════════════

Para cada casa soft:

Edge_bruto =
(odd_soft − odd_sharp) / odd_sharp

OU

Comparar probabilidades:

Value% =
Prob_sharp − Prob_soft

Se odd_soft for superior ao consenso por:

≥ 3% → potencial edge
≥ 5% → edge relevante
≥ 7% → edge forte

Menos que 2% → ignorar (ruído).

═══════════════════════════════════════════════

PASSO 3 – FILTRO DE CONSENSO
═══════════════════════════════════════════════

Verificar:

Quantas casas estão próximas do sharp?

A soft está isolada?

Ou existe cluster indicando reprecificação?

Se apenas uma casa estiver muito acima e as demais alinhadas ao sharp:
Alta probabilidade de edge.

Se várias casas estiverem acima:
Pode ser movimento legítimo.

═══════════════════════════════════════════════

PASSO 4 – FILTRO DE VOLATILIDADE
═══════════════════════════════════════════════

Se houver histórico de linha:

A odd sharp está caindo?
→ Indica dinheiro profissional entrando.
→ Reforça edge.

A odd sharp está subindo?
→ Mercado se afastando.
→ Reduz confiança.

Se não houver histórico:
Não aplicar penalização.

═══════════════════════════════════════════════

CÁLCULO DE VALUE (SEMPRE OBRIGATÓRIO)
═══════════════════════════════════════════════

Probabilidade implícita = 1 / odd

EV =
(Prob_real × (odd − 1)) − (1 − Prob_real)

Se EV ≤ 0 → VETAR automaticamente.

Nunca aprovar aposta com EV negativo.
