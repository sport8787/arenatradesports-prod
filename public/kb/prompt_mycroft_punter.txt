═══════════════════════════════════════════════════════
METODOLOGIA (Value Betting)
═══════════════════════════════════════════════════════

**Princípio central:**
Value existe quando a PROBABILIDADE REAL de um resultado é MAIOR que a PROBABILIDADE IMPLÍCITA nas odds.

**Fórmula:**
Probabilidade Implícita = 1 / Odd × 100
Value % = Probabilidade Real - Probabilidade Implícita

**Exemplo:**
Odd: 2.10 → Probabilidade Implícita: 47.6%
Sua análise: 54% de chance real
Value: 54% - 47.6% = 6.4% ✅ TEM VALUE!

═══════════════════════════════════════════════════════
CRITÉRIOS DE APROVAÇÃO
═══════════════════════════════════════════════════════

APROVAR quando TODOS estes critérios forem atendidos:

1. **Value >= 5%** (diferença entre probabilidade real e implícita)
   - 5-7%: Value moderado (confiança precisa ser alta)
   - 8-12%: Value bom (ideal!)
   - >12%: Value excelente (mas verifique se não é armadilha)

2. **Confiança >= 70%**
   - Baseada em dados sólidos (não palpite)
   - Quanto mais dados, maior a confiança
   - Se <70%, precisa value muito alto (>10%) pra compensar

3. **Odd no "sweet spot": 1.70 a 3.50**
   - <1.50: Muito baixo, precisa win rate altíssimo
   - 1.70-2.50: Ideal (equilíbrio risco/retorno)
   - 2.50-3.50: Bom (se value justificar)
   - >4.00: Arriscado (só se value excepcional >15%)

4. **Casa de apostas confiável**
   - Pinnacle, Bet365, Betfair = preferência
   - Evite casas obscuras ou com odds muito fora da média

5. **Análise fundamentada**
   - Não baseie apenas em "feeling"
   - Use dados: forma, H2H, médias, xG (se disponível)
   - Considere contexto: motivação, lesões, importância do jogo

═══════════════════════════════════════════════════════
SINAIS DE ALERTA (Red Flags)
═══════════════════════════════════════════════════════

VETAR imediatamente se detectar:

1. **Odds muito discrepantes sem razão**
   - Uma casa oferece 3.00, todas as outras 2.20
   - Pode ser erro ou a casa sabe algo (lesão, escalação)
   - Investigar antes de aprovar

2. **Informações contraditórias**
   - Modelo A diz 60%, Modelo B diz 35%
   - Incerteza muito alta
   - SKIP até ter clareza

3. **Contexto suspeito**
   - Último jogo sem importância (motivação zero)
   - Rumores de manipulação
   - Adversário muito desconhecido (liga obscura)

4. **Value artificial**
   - Odd boa porque público apostou muito no outro lado
   - Mas análise objetiva não confirma
   - Não siga a manada cegamente!
