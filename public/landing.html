O que é o Oráculo Mycroft?

O Oráculo Mycroft é uma plataforma profissional de análise esportiva que une dados ao vivo (API-Football, API-Futebol), modelos matemáticos (Distribuição de Poisson Bivariada, ODI — Odds Drift Index, BAS — Bluffer Asset Score) e a IA Mycroft (Gemini 2.5 Flash) para gerar sinais de apostas com fundamentação estatística.

A plataforma cobre futebol pré-jogo (Arena Punter), trading ao vivo (Arena Trader Sports), análise de escanteios, leitura situacional in-play e gestão automática de banca virtual.

Funcionalidades principais

  • Mycroft Sports (Trader ao Vivo): análise contínua de jogos in-play com até 3 oportunidades por partida (mercado primário + secundárias) e veredito ⚡ APROVADO, 🔥 LABAREDA, ⚠️ CUIDADO ou JOGO MORTO.
  • Mycroft Punter (Pré-jogo): sinais aprovados em odds 1.70–2.50 com BAS ≥ 70, edge mínimo, CLV positivo e regra anti-conflito de mercado.
  • Análise de Escanteios: 5 metodologias integradas (Dominância, Assimetria, Pressão, Set-Pieces, Late-Game).
  • Leitura Situacional (S1–S5): aprovação contextual por pressão posicional, virada iminente, late-game, etc.
  • 10 Planos Estratégicos: catálogo de planos como Labareda (fim de jogo), Cachorro Louco, Ressaca, Pressão Asfixiante, entre outros.
  • Banca virtual isolada: Trader Sports, Punter Hórus e Punter Manual com gestão independente, limite de exposição 15%.
  • Hórus (robô auto-bet): execução automática sincronizada por analysis_id.
  • Notificações Telegram + E-mail + Push: alertas de sinais APROVADOS, GREEN/RED, com deduplicação por match_id+market+verdict.
  • Modo Treino: cenários dinâmicos extraídos de partidas reais para prática sem risco.
  • Importação de extratos: Betfair Exchange e Sportsbook (CSV/PDF) com reconciliação automática.

Tecnologia

  • IA: Google Gemini 2.5 Flash (integração direta v1beta) para módulos críticos; Lovable AI Gateway para módulos auxiliares.
  • Dados: API-Football (Plano Ultra, 75k req/dia) + API-Futebol para cobertura brasileira; The Odds API para preços de mercado.
  • Backend: Supabase (Postgres + Edge Functions Deno + pg_cron + pg_net).
  • Frontend: React 18 + Vite + TypeScript + Tailwind CSS.
  • Análise quantitativa: Poisson Bivariada normalizada, fair odds reais, edge calculado, CLV monitorado.
