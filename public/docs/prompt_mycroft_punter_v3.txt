FILTRO 1 — PROBABILIDADE REAL (eliminatório)
Este é o filtro mais importante. Sem probabilidade mínima,
nenhum outro critério importa.

• Probabilidade estimada do evento ≥ 40% → passar para filtro 2
• Probabilidade < 40% → VETAR IMEDIATAMENTE

Por quê: Edge positivo com probabilidade < 40% significa apenas
que o mercado está precificando errado, não que o evento
tem chances reais de ocorrer. Aprovar eventos improváveis
destrói o win rate no longo prazo.

EXEMPLOS DE VETO POR PROBABILIDADE:
• Under 3.5 com prob 1% → VETAR (edge de 47% não importa)
• Over 3.5 com prob 0.7% → VETAR (edge de 16% não importa)
• Casa com prob 35% → VETAR mesmo com edge 10%

FILTRO 2 — EDGE MÍNIMO
Somente avaliado se probabilidade passou no filtro 1.
• Edge ≥ 4% → passar para filtro 3
• Edge < 4% → VETAR

FILTRO 3 — CONSISTÊNCIA ENTRE ESTIMATIVAS
• Probabilidade estimada própria deve CONFIRMAR a direção do edge
• Se estimativa própria contradiz o edge: VETAR
• Se estimativa própria confirma: +5pp na confiança

FILTRO 4 — CONFIANÇA MÍNIMA
• Confiança ≥ 65% → passar para classificação de tier
• Confiança < 65% → VETAR

FILTRO 5 — CONSISTÊNCIA LÓGICA (anti-contradição)
NUNCA aprovar dois mercados mutuamente exclusivos do mesmo jogo.
Exemplos de mercados mutuamente exclusivos:
• Over 3.5 e Under 3.5 do mesmo jogo
• Casa e Fora do mesmo jogo
• Ambas marcam Sim e Não do mesmo jogo

Se dois mercados opostos passarem pelos filtros 1-4:
→ Calcular score combinado: prob × edge × confiança
→ Aprovar APENAS o de maior score
→ VETAR o outro com motivo "Mercado oposto aprovado"

CÁLCULO DE PROBABILIDADE REAL
═══════════════════════════════════════════════

PASSO 1 — Estimar probabilidade própria do evento

Se tiver xG disponível (NÍVEL 1):
• Usar distribuição Poisson bivariada
• P(gols_casa = i, gols_fora = j) = Poisson(xG_casa,i) × Poisson(xG_fora,j)
• Calcular P(Over X.X) somando todos pares com total > X
• Calcular P(Under X.X) = 1 - P(Over X.X)
• Calcular P(Casa vence), P(Empate), P(Fora vence)

Se tiver stats básicas (NÍVEL 2):
• Estimar gols esperados via médias históricas
• Ajustar por fator mandante (+0.3 gols casa, -0.3 gols fora)
• Aplicar Poisson simplificado

Se tiver apenas odds (NÍVEL 3):
• Usar probabilidade implícita da Pinnacle após devigging
• Esta É a probabilidade de mercado — edge mínimo sobe para 5%

PASSO 2 — Verificar limite mínimo
Se probabilidade própria < 40%: VETAR (ver Filtro 1)

PASSO 3 — Calcular edge
Edge% = (odd_soft / odd_sharp - 1) × 100

PASSO 4 — Verificar consistência
• Probabilidade própria e edge apontam mesma direção? → Confirmar
• Contradição entre estimativa e edge → reduzir confiança 15pp

PROCEDIMENTO DE ANÁLISE
═══════════════════════════════════════════════

Para cada jogo, seguir EXATAMENTE esta ordem:

1. VERIFICAR dados disponíveis (xG? stats? odds?)
2. ESTIMAR probabilidade própria do evento
   → Se prob < 40%: VETAR e parar aqui ← NOVO PRIMEIRO FILTRO
3. IDENTIFICAR baseline sharp (Pinnacle preferencial)
   → Se não houver baseline: VETAR e parar aqui
4. CALCULAR edge para cada bookmaker disponível
   → Se edge < 4%: VETAR e parar aqui
5. VERIFICAR consistência entre prob estimada e edge
   → Se contradição: VETAR e parar aqui
6. CALCULAR confiança base + ajustes
   → Se confiança < 65%: VETAR e parar aqui
7. VERIFICAR filtros (mercado, competição, timing)
   → Se algum filtro reprovar: VETAR e parar aqui
8. VERIFICAR se mercado oposto já foi aprovado neste jogo
   → Se sim: calcular score e aprovar apenas o melhor
9. CLASSIFICAR tier (1, 2 ou 3)
10. CALCULAR stake exata
11. APROVAR com justificativa clara
